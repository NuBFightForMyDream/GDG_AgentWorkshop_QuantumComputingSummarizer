Course Assignment Step-by-Step Workflow Guide

Structured resolution protocols covering all 11 course tutorials and assignments.

Workflow 1: Single-Qubit Mechanics & Bloch Parameters (Assignment 1) Assg 1
1. Normalize vector $v = [c_0, c_1]^T \implies N = \sqrt{|c_0|^2 + |c_1|^2}$.
2. Calculate gate transformation $|\psi'\rangle = U \cdot |\psi\rangle$.
3. Extract Bloch polar angle $\theta = 2\arccos(|\alpha|)$ and azimuthal angle $\phi = \arg(\beta) - \arg(\alpha)$.
4. Compute expectation values $\langle X \rangle, \langle Y \rangle, \langle Z \rangle$.
Workflow 2: Bell State Generation & Entanglement Audit (Assignment 2-3) Assg 2-3
1. Expand tensor product $|\psi_{AB}\rangle = |\psi_A\rangle \otimes |\psi_B\rangle$.
2. Apply $H \otimes I$ followed by CNOT to synthesize Bell pair $|\Phi^+\rangle = \frac{1}{\sqrt{2}}(|00\rangle + |11\rangle)$.
3. Calculate density matrix $\rho_{AB} = |\psi_{AB}\rangle\langle\psi_{AB}|$ and partial trace $\rho_A = \text{Tr}_B(\rho_{AB})$.
4. Verify purity $P = \text{Tr}(\rho_A^2)$: $P=1 \implies$ Separable, $P=0.5 \implies$ Maximally Entangled.
Workflow 3: Quantum Teleportation & Superdense Coding (Assignment 3-4) Assg 3-4
1. Teleportation: Initialize state $|\psi\rangle_C \otimes |\Phi^+\rangle_{AB}$.
2. Apply $\text{CNOT}_{CA}$ and $H_C$, then measure qubits $C, A$ to obtain classical bits $(m_C, m_A)$.
3. Bob applies conditional Pauli gate $X^{m_A} Z^{m_C}$ to recover exact state $|\psi\rangle_B$.
4. Superdense coding: Alice applies $I, Z, X, iY$ to encode bits $00, 01, 10, 11$.
Workflow 4: Oracle Algorithms & Phase Kickback (Assignment 4-7) Assg 4-7
1. Deutsch-Jozsa: Query oracle $U_f$ with input $H^{\otimes n}|0\rangle^{\otimes n}$ and ancilla $|-\rangle$.
2. Measure input register: $|0\rangle^{\otimes n} \implies$ Constant, otherwise $\implies$ Balanced.
3. Bernstein-Vazirani: Oracle phase $(-1)^{s \cdot x}$ collapses deterministically to $|s\rangle$.
4. Simon: Collect $n-1$ linear equations $y \cdot s = 0 \pmod 2$ and solve via Gaussian elimination over $\mathbb{Z}_2$.
Workflow 5: QFT, QPE & Shor's Order Finding (Assignment 8-9) Assg 8-9
1. QFT: Construct circuit using Hadamard and Controlled-$R_k$ phase gates ($O(n^2)$ gates).
2. QPE: Apply controlled unitary powers $U^{2^j}$ to counting register followed by $QFT^\dagger$.
3. Shor: Find period $r$ of $f(x) = a^x \pmod N$ using QPE and continued fractions expansion.
4. Extract factors $p, q = \gcd(a^{r/2} \pm 1, N)$.
Workflow 6: Grover Search & Quantum Error Correction (Assignment 10-11) Assg 10-11
1. Grover: Repeat Oracle phase flip $I - 2|\omega\rangle\langle\omega|$ and Diffuser $2|s\rangle\langle s| - I$ for $R \approx \frac{\pi}{4}\sqrt{N}$ iterations.
2. QEC 3-Qubit: Encode $|0_L\rangle = |000\rangle, |1_L\rangle = |111\rangle$. Measure stabilizers $Z_1 Z_2, Z_2 Z_3$.
3. Map syndrome string $(s_1, s_2)$ to Pauli flip recovery operator $X_1, X_2, X_3$.
4. VQE: Evaluate expectation $\langle H(\vec{\theta}) \rangle$ on hardware and update parameters classically.
