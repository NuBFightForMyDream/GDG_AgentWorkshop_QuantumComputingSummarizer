Quantum Oracle
• Since it is an oracle, very often we do not know how it is implemented. We only know that its behavior
has some correlations to the problem that we try to solve.
• The problem we are solving usually is related to a function 𝑓 𝑥 (such as the 𝑓 𝑥 , which we want to
know if it is constant or balanced in the Deutsch algorithm).
• It can be as simple as a p-qubit identity gate (𝐼⨂𝑝). But usually, it is complex, and we can use some
physical systems to implement it.
• We will create an equivalent oracle when we need to test the circuit. But most of the time, we can just
treat it as a black box.
• There are two types of quantum oracles. One is called the XOR quantum oracle while the other is called
the phase quantum oracle.
• A quantum oracle is just a quantum gate. Therefore, it must be unitary and reversible. So, it is
represented as 𝑼𝑓, which is a unitary operator corresponding to the function 𝑓 𝑥 .

▪ For any function 𝑓(𝑥), it maps n bits of inputs to m bits of outputs. Mathematically, it is written as 𝑓: {0, 1}𝑛→ {0, 1}𝑚

▪ For example, in the Deutsch problem, we have 𝑛 = 𝑚 = 1. That is, both input and output have 1-qubit.
▪ In general, 𝑛 ≠ 𝑚, we can build a classical gate to map the n-bit inputs to the m-bit outputs. But we cannot do this in quantum

corresponding input in the reverse direction. Or an n-qubit input m-qubit output matrix is not square (it is 𝑚 × 𝑛) and thus it
cannot be unitary.

Grover’s Algorithm
• Computational Complexity
▪ Grover’s algorithm is a quantum search algorithm. It provides a quadratic speedup over the classical one.
▪ A computation problem usually takes more time as its size increases.
▪ For example, assume we do addition by adding each pair of single digits in a step. To do a 1-digit addition (e.g. 3 + 4), it might take
you 1 second. For a 2-digit addition (e.g. 13 + 24), it will take you about 2 seconds.
▪ If your computation efficiency does not decrease as the number of digits increases, it takes you about N seconds to compute an N-
bit addition. We say the computational complexity of this problem is 𝒪(𝑁). This means that the computation time goes up linearly
with the size of the problem (𝑁).
▪ If we find a method in which the computational complexity becomes 𝒪(𝑙𝑜𝑔𝑁), then the new algorithm achieves an exponential
speedup over the original one.
▪ The Deutsch–Jozsa Algorithm provides an exponential speedup over the classical algorithm. And its computational complexity is
just 𝒪 1 , which means it is independent of the size of the problem!
▪ However, not all quantum algorithms can provide an exponential speedup.
▪ Grover’s algorithm is such an algorithm that provides a quadratic speedup over the classical one.
▪ In reality, just comparing the algorithm speedup is incomplete. We also need to compare the amount of hardware required.
